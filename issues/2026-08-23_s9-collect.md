# 历史问题：Grok 候选收集

状态：历史 Playwright 传输层已废弃；资产身份和文件校验经验继续保留。

旧真网测试证明，生成请求被接受、页面进入 Post、DOM 出现图片或拿到预览截图，都不足以证明已经取得当前批次的完整原图。Grok 资产直读还可能因鉴权返回 403。

迁移后的不变量：

- 生成完成必须与当前批次稳定资产身份绑定。
- 参考图任务必须绑定本次上传标识，不能混入历史上传或历史生成图。
- 候选必须通过 Chrome/Grok 用户会话触发原图下载，再交给本地 CLI 校验。
- 页面缩略图、data URI、模糊预览和元素截图不能当作成功原图。
- MIME、魔数、完整性、尺寸和可解码性全部通过后才能冻结候选。
- 无法证明资产属于当前批次时失败，不用 URL 相似度猜测。

旧 response 监听、`page.evaluate(fetch)`、persistent Chromium profile 和 S9 脚本不再是现行方案。
